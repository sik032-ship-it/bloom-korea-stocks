# Project Memory

## Core
PPURI (뿌리) - Duolingo-style behavioral investing app for Korean US stock investors.
Primary green #58CC02, white bg, Noto Sans KR font. Mobile-first, max-w-lg.
Lovable Cloud enabled. Tables: profiles, holdings. Auth with auto-profile trigger.
Korean UI language. Gamification: streaks, levels (씨앗→숲), daily sentences.
No PracticePage (removed - duplicates lesson). No PaywallPage (removed - no payment yet).
No CommunityStats on home (hide until 100+ users). Home: greeting + CTA + level + 2 buttons only.
북극성: 장기투자 only, 타이밍/예측 금지. 위기 시 멘탈 코칭이 핵심. 이해 가능한 초우량 기업(애플/코카콜라/맥도날드 등)에만 집중. 종목 추천·단기매매·예측 콘텐츠 절대 금지.
