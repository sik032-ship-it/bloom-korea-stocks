# PPURI 확장 비전 (3 Phases)

**핵심 동기**: 한국 초중고에 금융/경제 교육이 필수가 아닌 상황. 시장 구조는 빠르게 변하는데 리터러시 공백이 큼. PPURI는 이 갭을 메우는 평생 학습 플랫폼으로 진화.

## Phase 1 (현재): 행동 투자 트레이너
- 보유 종목 기반 한 문장 쓰기, 위기 시뮬레이션, 일일 레슨, 스트릭

## Phase 2: 금융·경제 코칭 앱
- 듀오링고식 개념 Skill Tree (복리 → 인플레 → ETF → 채권 → 환율)
- 레벨별 커리큘럼 (씨앗/새싹/나무/숲)
- 인터랙티브 계산기 (복리, 은퇴자금, 환율)
- 오늘의 경제 뉴스 AI 요약 + 퀴즈

## Phase 3: 멘탈 코칭 (위기를 기회로)
- 하락장 대응 롤플레잉 훈련 (패닉 셀링 방지)
- 감정 일기 + AI 인지편향 진단 (FOMO, Loss Aversion, Anchoring)
- Crisis SOS: 매도 직전 본인 원칙 재확인 + 역사 사례
- 멘탈 멘토 매칭 (선택적, 익명 1:1)

## 의사결정 가이드
새 기능 제안 시 "이 기능이 Phase 2/3로 가는 길에 자연스럽게 연결되는가?" 검토. 단순 트레이딩 도구나 종목 추천 같은 방향은 거부 — PPURI는 **리터러시 + 멘탈 회복력**이 정체성.
