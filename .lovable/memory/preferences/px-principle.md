# Product Experience (PX) 원칙

우리 앱에서 가장 중요한 것은 **제품 완성도가 아니라 사용자 경험**이다.
UI가 경험을 만들고, 경험이 제품을 만든다.

## 작업 기준 (모든 결정에 적용)
1. **감정 곡선**: 각 화면에서 사용자가 느끼는 감정(안심·기대·성취·불안)을 먼저 설계.
2. **리텐션 행동**: 내일 다시 돌아오게 만드는 행동(스트릭, 완료감, 다음 기대)을 우선.
3. **마찰 최소화**: 탭 수·인지 부하·결정 피로를 줄이는 쪽을 항상 선택.
4. **셋의 균형**: 위 셋을 동시에 보고, 화면 성격에 따라 가중치를 조정.

## 판단 규칙
- "기능을 더 넣을까?"보다 "이 화면이 어떤 감정을 남기는가?"를 먼저 묻는다.
- 디자인 변경은 비즈니스 성과(리텐션·완료율)에 직접 연결되는 가설로 설명될 수 있어야 한다.
- 새 기능을 추가하기 전, 기존 여정의 마찰을 먼저 제거한다.
- 화면을 만들 때 항상 "첫 진입 → 핵심 행동 → 완료 → 재방문" 4단계로 검토.

## How to apply
- 모든 UI/UX 작업 전에 위 4단계 여정에서 어디를 다듬는지 명시한다.
- 메모리·태스크·코드 주석에 PX 관점의 의도를 남긴다.
