# 퀘스트 완주 → 레벨업 → 나무 성장 연결

## 목표
오늘의 퀘스트 맵 모든 스테이지를 완료하면 하나의 완주로 인정하고, 결과 화면에서 레벨 진행과 나무 성장을 연속해서 보여줍니다.

## 구현 내용
- 퀘스트 완료 조건을 오늘의 스테이지 전체 완료로 통일합니다.
- 마지막 스테이지 정답 후 `퀘스트 완주 → 도토리 획득 → 레벨 진행 → 나무 성장` 순서의 축하 화면을 표시합니다.
- 레벨이 오른 경우 이전/새 다람쥐 레벨을, 나무 단계가 오른 경우 이전/새 나무 모습을 실제 이미지로 전환해 보여줍니다.
- 홈으로 돌아오면 퀘스트 맵은 전부 완료 상태와 열린 도토리 상자를 표시하고, 나무 카드도 갱신된 단계와 진행률을 즉시 반영합니다.
- 복습·자유 도전은 다시 풀 수 있지만 일일 완주 보상과 성장 수치는 중복 지급하지 않습니다.

## 기술 메모
- 나무 단계·임계값·성장 판정은 기존 `treeGrowth` 규칙만 사용합니다.
- 레벨과 성장 저장은 기존 사용자 기록 갱신 흐름에서 한 번만 처리합니다.
- 일일 퀘스트 수(3/5/7)와 실제 오늘의 문제 세트를 그대로 사용합니다.

## 확인
- 마지막 스테이지 완료 후 축하 순서와 홈 갱신을 실제 로그인 상태로 확인합니다.
- 완료 후 복습/자유 도전에서 중복 성장하지 않는지 확인합니다.
- 모바일 화면에서 나무 전환과 버튼이 겹치지 않는지 확인합니다.
