# 오늘의 퀘스트 탐색형 게임 맵 업그레이드

## 구현 범위
- `TodayQuestPath`를 내부 세로 스크롤과 마우스·터치 드래그를 지원하는 긴 숲길 맵으로 바꿉니다.
- 처음 열릴 때 현재 진행 스테이지가 맵 중앙에 보이도록 자동 이동합니다.
- 완료·진행 중·잠김을 포함한 모든 노드를 누를 수 있게 하고, 선택한 스테이지의 프리뷰 패널을 표시합니다.
- 완료 스테이지는 복습, 진행 중 스테이지는 오늘의 미션, 잠긴 스테이지는 안내 후 자유 도전으로 기존 문제 화면에 연결합니다.
- 현재 스테이지 옆에 다람쥐와 응원 말풍선을 배치하고, 노드 누름·별·도토리 파티클 애니메이션을 추가합니다.
- 기존 오늘 진행률, 완료 기록, 도토리 보상, 나무와 홈의 다른 영역은 그대로 유지합니다.

## 동작 규칙
- 선택한 스테이지 번호를 문제 화면 주소에 전달해 해당 스테이지 문제부터 시작합니다.
- 복습과 자유 도전은 오늘의 완료 상태를 되돌리지 않으며, 기존 문제 저장 방식은 유지합니다.
- 키보드 사용자도 각 노드를 선택하고 프리뷰의 도전 버튼을 사용할 수 있게 합니다.
- 움직임 줄이기 설정에서는 반복 애니메이션과 파티클을 정지합니다.

## 확인
- 완료·진행·잠김 노드를 각각 눌러 프리뷰 문구와 이동 동작을 확인합니다.
- 모바일 폭과 데스크톱 폭에서 맵 스크롤, 자동 포커스, 글자 겹침을 확인합니다.
- 관련 자동 검사와 현재 미리보기 오류를 확인합니다.

## 기술 상세
- 별도 맵 라이브러리 없이 네이티브 세로 스크롤, Pointer Events, `scrollIntoView`를 사용합니다.
- 스테이지 선택은 `/lesson?quest=<번호>&mode=<challenge|review|free>` 형태로 전달하고, 문제 화면에서 해당 위치를 안전하게 적용합니다.
- 색상과 그림자는 기존 의미 기반 디자인 토큰만 사용합니다.
