# 문제 콘텐츠 전면 재설계

## 이해한 목표
이 앱의 문제는 금융 상식 시험이 아닙니다. 사용자가 매일 짧고 재미있게 반복하면서 아래 행동을 몸에 익히게 하는 훈련이어야 합니다.

1. MSFT·GOOGL·AMZN·AAPL처럼 이해할 수 있는 미국 우량 기업을 고른다.
2. 좋은 기업을 너무 비싸게 사지 않는다.
3. 가격이 흔들려도 사업이 훼손되지 않았다면 오래 머문다.
4. 버핏과 피터 린치의 지혜를 실제 상황에서 선택할 수 있게 만든다.
5. 어려운 용어를 외우는 대신, 하락장·뉴스·FOMO 앞에서 올바르게 행동한다.

현재 문제 풀은 심화 난이도에서 매크로·행동경제학 용어·역사 퀴즈·다른 투자자의 전략까지 섞여 이 목적을 흐립니다. 특히 ‘심화 + 골고루 섞기’는 모든 심화 문항을 무작위로 가져와 앱 철학과 거리가 먼 문제도 그대로 노출합니다.

## 개편 원칙
- **심화의 뜻 변경:** 어려운 용어가 아니라, 흔들리는 실제 상황에서 원칙을 적용하는 깊이로 정의합니다.
- **모든 문제를 앱 철학에 연결:** 각 문제는 10계명, Big 4의 사업 이해, 버핏/린치의 원칙, 장기보유 행동 중 하나를 반드시 훈련합니다.
- **기업 중심:** 주가·거시경제 지식보다 고객 습관, 브랜드, 전환 비용, 현금 창출, 부채, 재투자, 경영진 판단을 봅니다.
- **행동 중심:** “용어가 무엇인가?”보다 “이 상황에서 무엇을 할 것인가?”를 묻습니다.
- **초보도 이해 가능한 언어:** 전문용어가 필요하면 문제 안에서 뜻을 풀어주며, 암기형 빈칸과 출처 불명 명언은 제거합니다.
- **재미의 기준:** 사용자가 틀린 뒤 “아, 그래서 오래 보유하는구나”를 느끼는 반전과 짧은 코칭을 줍니다.

## 작업 내용
### 1. 문제 풀 정리
- 블랙스완, 안티프래질, MDD, 상관관계, 스태그플레이션, 금리 예측, 행동경제학 용어 암기처럼 목적에서 벗어난 문항을 제거하거나 생활 언어의 장기투자 상황 문제로 교체합니다.
- Big 4 외 개별 종목, 확인이 어려운 역사 수치·인용, 복잡한 금융상품 사례를 제거합니다.
- 비슷한 교훈을 표현만 바꾼 중복 문항을 줄입니다.

### 2. 철학 기반 커리큘럼 재구성
문제를 다음 6개 반복 훈련 축으로 재편합니다.
- 좋은 기업 알아보기: Big 4의 제품, 고객 습관, 해자
- 기업의 돈 이해하기: 현금흐름, 자본 효율, 부채를 쉬운 말로
- 오래 머무르기: 복리, 불필요한 매매, 사업과 가격 구분
- 폭락장에서 행동하기: -15/-25/-40 계획, 사업 훼손 확인, 패닉 방지
- 유혹 거절하기: FOMO, 테마주, 복잡한 상품, 모르는 기업 패스
- 버핏·린치처럼 생각하기: 실제 투자 상황에 원칙 적용

### 3. ‘심화 + 골고루 섞기’ 출제 방식 수정
- 단순 무작위 대신 한 세트 안에 `기업 이해 → 장기보유 → 위기 행동 → 거장의 지혜`가 고르게 들어오게 합니다.
- 심화 문제도 전문지식 시험이 아닌 사례 판단형으로 제한합니다.
- 오늘 이미 본 문제와 최근 문제는 계속 피하되, 철학 핵심 문제를 우선 출제합니다.
- 화면 문구도 “어려운 문제”가 아니라 “실전에서 흔들리지 않기”라는 의미가 드러나게 바꿉니다.

### 4. 주간 AI 문제 안전장치 강화
- 생성 전부터 6개 훈련 축과 버핏·린치 원칙 중 하나를 명시하게 합니다.
- 생성 후 `철학 연결`, `초보 이해 가능`, `실제 행동 선택`, `불필요한 전문용어 없음`, `사실 확인 가능`을 모두 통과한 문제만 저장합니다.
- 기준 미달이면 검증된 철학 문항으로 자동 대체합니다.

### 5. 검증
- 전체 정적 문제를 자동 검사해 금지 용어·Big 4 외 종목·철학 연결 누락을 잡습니다.
- 심화·골고루 섞기 세트를 여러 날짜로 시뮬레이션해 6개 축이 균형 있게 나오는지 확인합니다.
- 실제 화면에서 선택부터 정답·해설까지 풀어보며, 어려운 용어 없이 목적이 느껴지는지 검증합니다.

## 완료 기준
- 심화 문제를 풀어도 금융 시험처럼 느껴지지 않습니다.
- 매 세트에서 “좋은 기업을 고르고 오래 보유하는 법”이 분명히 반복됩니다.
- 버핏·피터 린치의 지혜가 이름 암기가 아니라 실제 선택 기준으로 등장합니다.
- 모든 해설이 사용자가 오늘 취할 행동 한 가지로 끝납니다.
